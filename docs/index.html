The deletion boundary

Useful enough to recover space.
Narrow enough to trust.

MAY CLEAN

Regenerable data

  • uv, Bun, Deno and Homebrew caches
  • Git-ignored node_modules and .next over 100 MB
  • Only inactive development projects
NEVER TOUCHES

Your actual work

  • Documents, Desktop, Downloads or media libraries
  • Git-tracked source, credentials or external volumes
  • Trash contents, Docker data or active projects
